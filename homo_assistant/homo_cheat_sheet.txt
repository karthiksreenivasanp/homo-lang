## Basic Syntax

1. Setting Variables:

set y as "hello"
set my_list as [1, 2, 3]

2. Printing to Screen:
show "Hello World"
show x

3. User Input:
ask "What is your name?" name

4. Arithmetic & Calculation:

calculate length as len(my_list)
calculate i as i + 1

5. Conditionals:
if x > 5
    show "x is big"
otherwise
    if x == 5
        show "x is 5"
    otherwise
        show "x is small"

6. Loops:
while i < 10
    show i
    calculate i as i + 1

repeat 5 times
    show "Hi"

for item in my_list
    show item

7. Functions:

    show "Hi " + name
    return "Done"

call say_hi "Alice"
set result_val as result

## Important Rules for Homo Code
- No brackets `{}` or semicolons `;`.
- Indentation is strict! Use 4 spaces for block indentation inside `while`, `for`, `if`, `otherwise`, and `define`.
- To update an array item: `set arr[i] as val`. Note that `i` must be a single variable or digit (e.g., `set arr[j_next] as val`, DO NOT DO `set arr[j+1] as val`).
- Array slicing is supported (e.g., `arr[0:mid]`).
- Do NOT output python code. Only output Homo code.
