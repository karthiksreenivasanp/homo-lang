# Contributing to Homo Language

First off, thank you for considering contributing to Homo! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub with:
1. A clear and descriptive title.
2. The exact steps to reproduce the issue.
3. The expected behavior vs what actually happened.

### Suggesting Enhancements
Have an idea to make the language better or even simpler for kids? We'd love to hear it! Open an issue describing your idea and how it would improve the language.

### Pull Requests
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests to `run_tests.py` or the `tests/` directory.
3. Ensure the test suite passes (`python run_tests.py`).
4. Update the `README.md` with any new syntax or features.
5. Issue that pull request!

## Code Style
Keep the Python backend clean, highly readable, and well-commented. Remember that the goal of this language is to be as simple as possible for younger learners to use.
